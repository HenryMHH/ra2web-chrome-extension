# RA2 Web 辅助小工具 [[zh-TW](https://github.com/HenryMHH/ra2web-chrome-extension/blob/main/README.md)] [[EN](https://github.com/HenryMHH/ra2web-chrome-extension/blob/main/README-EN.md)]

红色警戒 2 网页版的 Chrome 扩展,让你打 Chrono Divide / ra2web 的时候看得更清楚、玩得更轻松。

支持网站:`https://game.ra2web.com`。

## 安装与使用

下载最新版本 [Ra2 Web Assitant](https://github.com/HenryMHH/ra2web-chrome-extension/releases/tag/v1.0.0) (extension.zip)

到 Chrome `chrome://extensions`,开启“开发者模式”,点“加载已解压的扩展程序”,选择 `extension/` 文件夹。

进入游戏后,点浏览器工具栏的扩展图标打开设置面板,勾选想要的功能再按“应用”。

## 功能

### 单位名称

- 每个单位头上会显示名字,一眼看清场上有什么
- **颜色分阵营**:敌人红色、自己和盟友蓝色、中立绿色,不会看错目标
- 字体大小可调(10–20 px),适配不同屏幕和缩放
- 中立单位(平民、动物)可以单独隐藏,画面更干净

### 画面外敌人指示器

- 屏幕边缘会出现**红色箭头**,告诉你画面外哪边有敌人
- 箭头旁边还会显示是什么单位,提前准备防守

### 宝箱内容

- 地图上的宝箱会直接标出**里面是什么**(中文)
- 15 种宝箱类型可以自己挑要看哪些:装甲↑、火力↑、金钱、揭示地图、速度↑、老兵升级、免费单位、无敌护盾、矿石、隐形、黑雾、爆炸、核弹、燃烧、基地回复
- 想抢好东西、想躲核弹宝箱都很方便

### 隐藏特定单位

- 不想看到的单位可以打勾隐藏(例如矿车、狗、平民)
- 有搜索框、全选 / 全不选按钮
- 可以把当前的设置**存成预设组合**,下次一键切换,适合不同打法

### 其他

- 设置**自动保存**,下次打开游戏自动应用,不用每次重设
- 扩展图标会根据是否启用变色,一眼知道状态
- 不修改任何游戏文件,纯粹叠在画面上
