# RA2 Web Assistant

A Chrome extension for the Red Alert 2 web port — makes Chrono Divide / ra2web easier to read and play.

Supported site: `https://game.ra2web.com`.

## Install & Use

Download the latest release [Ra2 Web Assitant](https://github.com/HenryMHH/ra2web-chrome-extension/releases/tag/v1.0.0) (extension.zip).

Go to Chrome `chrome://extensions`, enable "Developer mode", click "Load unpacked", and pick the `extension/` folder.

Once in-game, click the extension icon in the toolbar to open the settings panel, toggle the features you want, then hit "Apply".

## Features

### Unit Names

- Every unit shows its name above its head — instantly see what's on the field
- **Color-coded by faction**: enemies red, self and allies blue, neutral green — no target confusion
- Adjustable font size (10–20 px) for different screens and zoom levels
- Neutral units (civilians, animals) can be hidden separately for a cleaner view

### Off-Screen Enemy Indicators

- **Red arrows** at the screen edge point to enemies outside the viewport
- Each arrow shows the unit name next to it — prep defense before contact

### Crate Contents

- Crates on the map are labeled with **what's inside** (Chinese)
- 15 crate types selectable: Armor↑, Firepower↑, Money, Reveal Map, Speed↑, Veteran, Free Unit, Shield, Ore, Cloak, Dark Fog, Explosion, Nuke, Napalm, Heal Base
- Easy to grab good loot or dodge nuke crates

### Hide Specific Units

- Check off units you don't want to see (e.g. miners, dogs, civilians)
- Search box, select all / none buttons
- Save current selection as a **preset**, swap with one click — fits different playstyles

### Misc

- Settings **auto-saved** and re-applied next session — no re-configuring
- Extension icon changes color based on active state — status at a glance
- Touches no game files — pure overlay on top
